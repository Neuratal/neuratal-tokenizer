# Support NTokenizer

NTokenizer is an independent, community-supported project by Neuratal. Here is how you
can help — no purchase or sponsorship is required or implied.

## Ways to support

1. **Star the repository** — it is the simplest signal that the project is useful.
2. **File bug reports** — crashes, wrong bytes, surprising tokenizations, unclear docs.
   Include a minimal reproducer and your platform (see CONTRIBUTING.md).
3. **Request features** — open an issue describing your use case (training a new model?
   serving? research comparison?).
4. **Contribute code** — see CONTRIBUTING.md. Unicode handling, multilingual fixtures,
   benchmarks and documentation fixes are especially welcome.
5. **Contribute benchmarks** — new multilingual evaluation files with clear licensing are
   valuable; please confirm redistribution rights before submitting data.
6. **Improve documentation** — examples, installation instructions, translations of docs.
7. **Cite the project** in research or technical work (see `CITATION.cff`).
8. **Share the project** with people working on multilingual NLP or Rust ML tooling.

## What this project does not have

There is currently **no** official sponsorship, donation, grant, grant partner, or
funding channel. If one appears in the future it will be announced here and on the
repository's README, and it will be linkable to an official Neuratal-controlled channel.
Please disregard unofficial solicitation and report look-alikes.

## Getting help

- Bugs and usage questions: GitHub Issues on
  <https://github.com/Neuratal/neuratal-tokenizer>
- Security issues: see `SECURITY.md`
- General NLP and tokenizer engineering: GitHub Discussions (when enabled)

Please include your NTokenizer version, OS, and a byte-exact reproducer where possible.
