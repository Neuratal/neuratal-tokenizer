# Code of Conduct

Neuratal and the NTokenizer project are committed to a respectful, professional and
inclusive community.

## Expected behavior

- Be respectful and constructive in issues, pull requests, discussions and reviews.
- Criticize ideas and code, not people.
- Assume good faith; ask clarifying questions before assuming bad intent.
- Be especially careful with Unicode, language and accessibility topics — this project
  is multilingual by design.

## Unacceptable behavior

- Harassment, personal attacks, discrimination or threats.
- Publishing another person's private information without consent.
- Deliberately misleading claims about this project's benchmarks, licensing or capabilities.

## Enforcement

Report conduct concerns by opening a GitHub issue (or, for sensitive reports, via the
contact options listed in SUPPORT.md). Maintainers may remove comments, close issues or
ban participants from the project space when this code of conduct is violated.

## Scope

This code of conduct applies to all project spaces: this repository, its issue tracker,
pull requests, discussions, and any official Neuratal distribution channels.
